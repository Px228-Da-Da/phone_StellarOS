# Разблокировка загрузчика (обязательный шаг, ~7 дней ожидания)

Без этого LK откажется грузить наш неподписанный образ.

## Порядок

1. **Аккаунт Mi.** Настройки → Mi аккаунт — войти. Аккаунт должен быть создан
   заранее (Xiaomi требует «возраст» аккаунта).
2. **Привязать устройство.** Настройки → Расширенные настройки → Для разработчиков:
   - включить «Параметры разработчика» (7 тапов по «Версия MIUI»)
   - «Заводская разблокировка» (OEM unlocking) — ON
   - «Статус Mi Unlock» → «Добавить аккаунт и устройство»
   - В телефоне должна быть SIM и включён **мобильный интернет** (не Wi-Fi)
3. **Ждать 168 часов.** Xiaomi выдаёт разрешение через 7 суток. Аккаунт из
   телефона выходить нельзя.
4. **Mi Unlock Tool** (Windows): https://en.miui.com/unlock/
   Либо MiUnlockTool из WSL — см. «Запасной путь» ниже.
   - Телефон выключить, зажать **Vol- + Power** → fastboot (кролик с чинящим роботом)
   - Подключить USB, в программе войти тем же Mi аккаунтом, `Unlock`
   - **Все данные будут стёрты.**

## Проверка

```powershell
fastboot devices
fastboot oem device-info
# должно быть: Device unlocked: true
```

## Если Mi Unlock ругается на драйверы

Windows 11 требует подписанные драйверы MTK. Проще: делать fastboot из **WSL**
c `usbipd-win` (проброс USB в Linux) — там драйверы не нужны.

```powershell
winget install usbipd
usbipd list
usbipd bind --busid <BUSID>
usbipd attach --wsl --busid <BUSID>
```

## Запасной путь: MiUnlockTool (без Windows)

https://github.com/MiForge/MiUnlockTool — открытая замена официальной утилиты
на Python. Ходит на **тот же** сервер Xiaomi тем же способом: по словам их FAQ,
«follows the exact same official process as Xiaomi's official tool».

Зачем он нужен: официальная утилита есть только под Windows и требует
подписанных MTK-драйверов. Этот работает из WSL, где уже стоит вся наша сборка,
и проброс USB через `usbipd` там уже настроен (см. выше).

```bash
# в WSL, один раз
sudo apt install python3 python3-venv
python3 -m venv ~/miunlock-env
source ~/miunlock-env/bin/activate
pip install miunlock

# в день разблокировки: телефон в fastboot, USB проброшен в WSL
source ~/miunlock-env/bin/activate      # окружение живёт только в этой сессии
miunlock
```

Дальше утилита сама спросит логин — **тот же аккаунт Mi**, что привязан
в «Статус Mi Unlock». Другой аккаунт даст ошибку 20033.

Чего он **не** делает: не сокращает 168 часов. Ожидание держит сервер Xiaomi,
клиент на это не влияет никак.

### Коды ответов сервера

Пригодится, чтобы не гадать над очередным числом.

| Код | Что означает |
|---|---|
| 20036 | «Please unlock *** hours later» — таймер ещё идёт, в сообщении точное число часов |
| 10013 | Устройство активировано меньше 7 суток |
| 20031 | Аккаунт не привязан: Настройки → Для разработчиков → Статус Mi Unlock |
| 20033 | Не тот аккаунт — нужен именно привязанный к устройству |
| 10023 | Лимит устройств на аккаунт исчерпан (с 2025 года — **одно в год**) |
| 20030 | Исчерпан месячный лимит выдачи токена |
| 20038 | Устройство привязано к чужому аккаунту |
| 20039 | Проверка данных устройства не прошла — разблокировка недоступна |
| 20041 | К Mi ID не привязан номер телефона |
| 20045 | Регион регистрации аккаунта не совпадает с регионом продажи телефона |
| 30002 | Нужна заявка в Mi Community (актуально для HyperOS) |
| 20035 | Требуется более свежая версия утилиты |

### Две вещи, о которых стоит знать заранее

**Попытка одна.** Код 10023: с 2025 года на аккаунт разблокируется одно
устройство в год. Если привязка слетит и придётся начинать заново — второго
телефона на этот аккаунт в этом году уже не будет.

**Не пробовать «а вдруг уже можно».** Выдача токена ограничена по месяцам
(код 20030). Каждая попытка тратит лимит, поэтому лучше дождаться даты
и сделать один раз, чем прощупывать сервер каждый день.

**Про доверие.** Утилита логинится вашим Mi-аккаунтом. Сам логин делает не она,
а её зависимость — пакет `migate` (ставится автоматически). При входе через
терминал пароль вводится в неё напрямую, поэтому грепать на `password` один только
репозиторий MiUnlockTool бесполезно: там его нет, он в `migate`.

Способов входа три: `1` браузер, `2` терминал, `3` QR-код. Варианты 1 и 3 не требуют
набирать пароль в консоли — если это смущает, берите их.

Сетевые адреса самой утилиты — только серверы Xiaomi:
`unlock.update.intl.miui.com` и региональные `eu-` / `in-` / `ru-`. Посторонних нет.

### Как прошло у нас (04.09.2026)

Официальная Mi Unlock **этот телефон не увидела в принципе**: в fastboot он
представляется как `VID_0BB4&PID_0C01` (идентификатор HTC — MediaTek использует его
в LK), а драйвер `android_winusb.inf` из пакета Mi Unlock описывает только
`2717:D00D` и `18D1:D00D` — аппараты Xiaomi на Qualcomm. MTK туда не попадает.
Отсюда `Status: Error` в диспетчере устройств и пустой `fastboot devices`.

Сработал путь через WSL: `usbipd` + MiUnlockTool. Вход методом `2` (терминал),
2FA по email. Аккаунт региона **UA** → зона `Singapore` → сервер
`unlock.update.intl.miui.com`. Зону менять не нужно: в коде утилиты список Europe
состоит только из стран ЕС, Украины там нет, и `else` даёт международный сервер —
это правильный адрес, а не запасной.

Результат: `unlocked: yes`, `secure: no`.

## Важно

После разблокировки **не обновлять MIUI по воздуху** — обновление может
вернуть блокировку и перезаписать LK.
