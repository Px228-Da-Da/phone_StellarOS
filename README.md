# VELO-OS — своя ОС на своём ядре для Redmi Note 9 (merlin)

Bare-metal ядро AArch64, которое грузится вместо Linux на MediaTek Helio G85.

**Статус: этап 1 пройден, начат этап 3.** Ядро собирается, стартует в QEMU, спускается в EL1,
читает DTB, тикает по системному таймеру, ловит исключения и печатает панику.

```
================================
  VELO-OS v0.1
  AARCH64 BARE METAL KERNEL
================================

EL       : 1
MPIDR    : 0000000080000000 (CORE 0)
CNTFRQ   : 62500000 HZ
DTB SIZE : 1048576 BYTES, VER 17

BOOT OK. HEARTBEAT:
TICK 0
```

---

## Как это работает

Мы **не пишем всё с нуля до последнего транзистора** — это невозможно в одиночку.
Мы встраиваемся в существующую цепочку загрузки MediaTek на последнем звене:

```
BROM -> preloader -> ATF -> LK -> [ЗДЕСЬ МЫ]
```

К моменту, когда управление доходит до нас, preloader уже настроил и откалибровал
LPDDR4X, а LK уже включил экран. Нам достаётся работающая память и работающая
панель — остаётся написать саму ОС. Подробно: [docs/03-boot-chain.md](docs/03-boot-chain.md).

## Быстрый старт

```bash
# один раз: инструменты в WSL
wsl -u root bash /mnt/d/OS_ANDROID/tools/setup-wsl.sh

# каждый день: сборка и запуск в эмуляторе
wsl -u root bash -c 'cd /mnt/d/OS_ANDROID/kernel && make BOARD=qemu && make run'
```

Ctrl+A затем X — выйти из QEMU.

## Структура

```
kernel/src/boot.S      точка входа: Image header, парковка ядер, EL2->EL1, стек
kernel/src/vectors.S   таблица векторов исключений (без неё падение = чёрный экран)
kernel/src/main.c      kmain, диагностика, обработчик паники
kernel/src/fb.c        фреймбуфер: находим буфер LK и пишем в него пиксели
kernel/src/uart.c      PL011 (QEMU) и MTK 8250 (телефон)
kernel/src/print.c     kprintf — печатает сразу и в UART, и на экран
kernel/src/soc/        карты регистров MT6769 и QEMU virt
tools/                 setup, упаковка boot.img, прошивка и откат
docs/                  устройство, безопасность, разблокировка, цепочка загрузки
```

## Два ключевых решения проекта

**1. Всё сначала в QEMU.** Каждая фича доводится в эмуляторе и только потом
едет на телефон. Один цикл «прошил — чёрный экран — откатил» стоит 10 минут,
цикл в QEMU — 10 секунд.

**2. Экран вместо UART.** До UART на этом телефоне нужно паяться к тест-пойнтам.
Вместо этого мы читаем адрес фреймбуфера прямо из регистра контроллера дисплея
(его настроил LK, когда рисовал логотип) и пишем туда текст сами. `kprintf`
выводит в оба канала, так что один и тот же код отлаживается везде.

устроена работа над любым ядром, включая Linux.

## Что честно сказать про границы

Модем, Wi-Fi, Bluetooth, камера и GPU на MediaTek закрыты и не документированы.
Полноценной заменой Android эта система не станет. Целью стоит другое:
собственное работающее ядро на настоящем железе — с графикой, вводом,
многозадачностью и многоядерностью.

Откат к заводскому Android — одна команда: `tools/flash.sh --restore`.
